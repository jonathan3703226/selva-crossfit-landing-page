Landing page institucional e responsiva desenvolvida para a **SELVA CrossFit Box**. O foco arquitetural do projeto foi a construção de uma interface rica em interatividade utilizando **exclusivamente HTML5 e CSS3**, explorando o potencial do CSS moderno para controle de estados sem nenhuma linha de JavaScript.

> Uma aplicação front-end focada em demonstrar a capacidade de resolver problemas complexos de UI/UX — como alternância de temas, carrossel de imagens, flip cards 3D e sistema de abas — através do uso avançado do CSS (Zero JS).

## 🚀 O Projeto & Estudo de Caso

O projeto **SELVA CrossFit Box** nasceu como um estudo de caso prático focado na construção de comportamentos dinâmicos sem a necessidade de frameworks ou scripts client-side. O objetivo principal foi testar os limites do CSS3 e demonstrar domínio em arquitetura de código, acessibilidade e padrões de validação web.

**Diferencial Técnico (Arquitetura No-JS & Validação W3C):**
Comportamentos que tradicionalmente dependem de manipulação do DOM via JavaScript foram resolvidos exclusivamente em CSS com a técnica do *Checkbox Hack* (pseudo-classe `:checked`), seletores de sibling (`~` e `+`) e transições 3D. Além disso, todo o código passou por testes rigorosos de qualidade e semântica estrutural.

### 🎯 Desafios Técnicos Superados (Sem JS):

*   **Dark/Light Mode NATIVO:** Inversão global e fluida de tema baseada em CSS Custom Properties (Variáveis CSS) manipuladas por seletores de estado.
*   **Flip Cards 3D (Seção "O Líder"):** Cards interativos com perspectiva e efeito de rotação tridimensional no eixo Y (`transform: rotateY`) no hover/tap.
*   **Carrossel de Imagens:** Navegação e navegação de fotos controlada integralmente por inputs ocultos e seletores de CSS.
*   **Sistema de Abas (Tabs):** Alternância entre a exibição da listagem de avaliações dos alunos e o formulário de submissão sem recarregar a página.
*   **Menu Responsivo (Mobile Toggle):** Menu hambúrguer totalmente funcional para telas menores sem dependência de scripts.

## ✨ Funcionalidades (Features)

*   **Alternador de Tema (Dark / Light Mode):** Ajuste de contraste e paleta visual via CSS puro.
*   **Hero Section Imersiva:** Banner inicial focado em conversão de novos alunos.
*   **Galeria e Carrossel No-JS:** Exibição de instalações e equipamentos sem scripts externos.
*   **Mídia de Fundo (Seção Habitat):** Background em vídeo com sobreposição opaca para melhor leitura dos textos.
*   **Cards de Planos e Modalidades:** Tabela e cards comparativos organizados via CSS Grid.
*   **Garantia de Qualidade W3C:**
    *   **HTML5:** Testado via [W3C Markup Validator](https://validator.w3.org/) (zero erros e avisos, com correta hierarquia de headings e uso de tags semânticas como `<header>`, `<article>`, `<nav>`).
    *   **CSS3:** Aprovado via [W3C CSS Validation Service](https://jigsaw.w3.org/css-validator/).

---

## 🛠️ Tecnologias Utilizadas (Stack)

*   **HTML5:** Estruturação semântica limpa, acessível e otimizada para SEO.
*   **CSS3 (Puro & Avançado):**
    *   **Custom Properties (Variáveis CSS):** Gerenciamento centralizado de temas e cores.
    *   **Flexbox & Grid Layout:** Construção da estrutura responsiva adaptável.
    *   **3D Transforms & Keyframes:** Animações e efeitos visuais suaves.
    *   **Checkbox Hack (`:checked`):** Gerenciamento de estado da interface sem uso de JavaScript.
*   **Assets externos:** Google Fonts e FontAwesome.

## ⚙️ Como Executar Localmente

Por ser uma aplicação estática e sem dependências externas de build ou requisições assíncronas, não é necessário rodar um servidor de desenvolvimento pesado.

1. Clone o repositório:
   ```bash

4. O navegador abrirá automaticamente a aplicação.
